# Owly releases

Public downloads for Owly for Windows. Get the newest installer from
[the latest release](https://github.com/c31labs/owly-releases/releases/latest), or from
[company31.com/owly](https://company31.com/owly/).

The setup is not code-signed yet, so Windows SmartScreen may warn when you run it. Each release lists
the installer's SHA-256 so you can check it with `Get-FileHash OwlySetup.exe`.
